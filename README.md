# Trabalho Prático - Projeto e Análise de Algoritmos

Trabalho Prático da disciplina de Projeto e Análise de Algoritmos.

## Linguagem

C

## Estrutura

O trabalho é dividido em nove tarefas:

1. Multiplicação de matrizes utilizando divisão e conquista
2. Dijkstra utilizando vetores
3. Dijkstra utilizando listas encadeadas
4. Dijkstra utilizando fila de prioridade
5. Caminho mínimo utilizando busca completa
6. Caminho mínimo utilizando backtracking
7. Estratégia gulosa para caminho mínimo
8. Caminho mínimo utilizando metaheurística
9. Caminhos mínimos utilizando programação dinâmica

## Organização

Cada tarefa possui seu próprio diretório contendo código-fonte,
arquivos de cabeçalho e casos de teste.

## Compilação

As instruções de compilação serão adicionadas conforme as tarefas
forem implementadas.

## Execução

Os programas serão executados via linha de comando em ambiente Linux.

## Relatório

O relatório final será disponibilizado no diretório `relatorio/`.
